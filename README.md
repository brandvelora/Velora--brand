# VELORA — Wear Your Identity.

Static fashion brand website (no build step).

- `index.html` — the whole site (HTML, CSS, JS)
- `images/` — replace these files to change photos (keep the same filenames):
  `velora-logo.png`, `velora-hero-01..03.jpg`, `velora-editorial-01..03.jpg`

Deploy on GitHub Pages: push to a repo, then Settings → Pages → deploy from branch `main` (root).
